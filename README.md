# Geospatial File Measurement API

A backend service built with FastAPI that accepts geospatial files such as KML and Shapefile ZIP archives, processes their features, handles coordinate reference systems, and calculates measurements such as polygon area and LineString length.

## Status

🚧 Project under development.

## Planned Features

- KML upload
- Shapefile ZIP upload
- Feature extraction
- CRS detection
- CRS transformation
- Polygon area calculation
- LineString length calculation
- Measurement persistence
- REST APIs
- PostgreSQL database
- Automated tests
